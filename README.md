## 💻 Local Development Setup

### Prerequisites
- Node.js >= 18.18.0 (Node 22 recommended)
- npm >= 9.0.0

### Installation
```bash
# Clone the repository
git clone https://github.com/MOHIT17717/portfolio.in.git
cd portfolio.in

# Install dependencies
npm install

# Start local development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Production Build
```bash
# Compile optimized static build
npm run build

# Preview production build locally
npm run start
```

## 🌐 Public Deployment Instructions

### Deploying via Vercel (CLI)


1. Push repository commits to `https://github.com/MOHIT17717/portfolio.in`.
2. Connect the repository in the [Vercel Dashboard](https://vercel.com/new).
3. Framework Preset: **Next.js**.
4. Root Directory: `./`.
5. Click **Deploy**.
